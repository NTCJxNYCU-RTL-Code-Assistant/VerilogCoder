- **Data Acceptance**: The `accept` signal is asserted when `in_ready` is high and the module is not currently calculating (`calc` is low). Upon acceptance, it modifies the input `in` by XORing it with a portion of `out`, forming `round_in`, then feeds it as a part of the round function.

- **Round Operations**: 
  - On each clock cycle when `update` is true, `round_dut` is called with the `round_in` and a dynamically generated round constant `rc` from `rconst_dut`.
  - The `round_out` from `round_dut` updates `out`.
   
- **State Transition**: The internal register `i` acts as a shift register to determine when the final round (23rd) is completed. When `i[22]` is set, the calculation cycle completes, and `out_ready` is signaled to be true on the next `update` cycle.
