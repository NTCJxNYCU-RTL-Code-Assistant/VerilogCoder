3. **Power calculations**:

5. **Control Reported Syndromes**:
   - A control state machine drives updating and output of syllables (`s0` to `s15`) upon `S_Ready_0` assertion.
   - `S_Ready` is asserted once all syndrome values are computed and outputs stabilize.
